## Entrega inicial
- `Documento_Inicial_ParkControl.docx`: objetivos, justificación, tecnologías y requerimientos.
- `base_de_datos.sql`: creación de base de datos MySQL y registros de prueba.
- `Diagrama_DER.png`: diagrama entidad-relación.

## Ejecución de la base de datos
Abrir MySQL Workbench, conectarse al servidor, abrir `base_de_datos.sql` y ejecutar el script completo sobre una instalación de MySQL 8 o superior. El script es para una base nueva; repetirlo sin limpiar tablas puede causar duplicados.
